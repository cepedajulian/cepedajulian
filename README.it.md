**Sviluppatore software | Backend e sviluppo web full stack**

Progetto e sviluppo applicazioni web, con particolare attenzione all'architettura backend, alla modellazione dei dati e alla manutenibilità del codice. Lavoro principalmente con PHP, JavaScript e MariaDB, dalla definizione delle regole di business fino all'implementazione e alla distribuzione in produzione.

Il mio obiettivo è realizzare soluzioni pratiche, sicure ed efficienti, scegliendo gli strumenti più adatti alle esigenze di ciascun progetto.

## Aree di specializzazione

- **Sviluppo backend:** applicazioni PHP, architettura MVC, API REST e componenti riutilizzabili.
- **Database:** modellazione relazionale, SQL avanzato, procedure memorizzate e ottimizzazione delle query.
- **Sistemi gestionali:** processi accademici e amministrativi, logica di business e report statistici.
- **Infrastruttura:** distribuzione e amministrazione di applicazioni con Linux, Nginx, Docker e servizi cloud.
- **Sviluppo frontend:** interfacce web con HTML, CSS e JavaScript, privilegiando soluzioni semplici e manutenibili.
